# 彭林 / Lin Peng

中英双语学术主页，包含个人简介、研究方向与教育经历。

- `index.html`：中文页面。
- `en.html`：英文页面。
- `styles.css`：电脑与手机共用的响应式样式。
- `favicon.svg`：网站图标。

网站使用纯 HTML 和 CSS，无需安装依赖或构建。语言切换和页面导航不依赖 JavaScript。

## 本地预览

在仓库根目录执行：

```bash
python -m http.server 8000
```

访问 `http://localhost:8000/`。

## 内容维护

修改简介、研究方向或教育经历时，同时更新 `index.html` 和 `en.html`。博士阶段为 2022–2028 年，其中 2028 年标注为预计毕业。
